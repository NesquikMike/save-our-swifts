# Save Our Swifts

A simple promotional website for the Wenhaston, Suffolk volunteer group that helps migrating swifts find safe nest sites each summer.

## Preview

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Contents

- `index.html` — page structure and copy
- `css/styles.css` — layout and visual design
- `js/main.js` — navigation and scroll reveals
- `assets/swifts_at_the_church_more_birds_near_church_tower.jpg` — hero photograph
